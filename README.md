# Hermex

Active-learning Chrome extension that turns YouTube into a tutor: auto-generated checkpoint quizzes pause the video, a side panel provides chat, generated study materials, and a recap.

## Layout

- **`extension/`** — current work. Manifest V3 Chrome extension (React + Vite + Tailwind). This is what you install.
- **`old/`** — the original web app (React frontend + Flask backend). Kept for reference; the Flask backend is still used by the extension, the React frontend has been replaced.

See `extension/README.md` for install and development notes.
